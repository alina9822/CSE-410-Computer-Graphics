# CSE 410 - Computer Graphics

This repository contains the coursework and programming assignments completed for the Computer Graphics course. The work is organized into three major offline labs, each focused on different graphics concepts such as OpenGL rendering, geometric transformations, rasterization, and ray tracing.

## Offline 1: OpenGL scene and animation

Location: `offline1/1905099`

This section contains basic OpenGL programs that demonstrate graphics primitives, transformations, camera interaction, and animated scenes.

### Included files
- `rolling_ball.cpp` — rolling ball / board-style graphical scene with 3D animation and transformations.
- `newRolling_ball.cpp` — another implementation of a rolling object animation, likely an experimental or updated version.
- `magic_cube.cpp` — a magic cube / cylindrical geometric construction using OpenGL primitives.
- `show` — compiled binary output.
- `task2` — additional task artifact or helper output.

### Typical build command
```bash
cd offline1/1905099
g++ rolling_ball.cpp -o show -lglut -lGLU -lGL
./show
```

## Offline 2: 3D transformation and view pipeline

Location: `offline2/1905099`

This assignment focuses on the graphics pipeline: reading object definitions, applying transformation matrices, projecting triangles, and generating rendered output from stage files.

### Included files
- `1905099.cpp` — main program implementing matrix-based object transformations and rasterization logic.
- `bitmap_image.hpp` — utility for writing bitmap image files.
- `show` — compiled binary.
- `IOs/` — input/output data files for multiple stages and z-buffer scenarios.

The `IOs` directory contains stage configuration and scene files used to test different viewpoints, transforms, and rendering stages. This is a good example of a pipeline-based graphics assignment where the scene is described by text input and converted into visual output.

### Typical build command
```bash
cd offline2/1905099
g++ 1905099.cpp -o show
./show
```

## Offline 3: Ray tracing and shading

Location: `offline3/1905099`

This lab implements a simple ray-tracing renderer with geometric primitives, lighting, and shading. It uses a custom math and object model to compute intersections, apply lighting equations, and export rendered frames as bitmap images.

### Included files
- `1905099_main.cpp` — main rendering loop and ray generation logic.
- `1905099_headers.h` — geometry, color, light, camera, and object classes used by the renderer.
- `input.txt` — scene description containing objects, lights, camera setup, and rendering parameters.
- `bitmap_image.hpp` — image output library.
- `Output_11.bmp` — generated sample output image.

This assignment models spheres, triangles, point lights, and shading terms such as ambient, diffuse, and specular reflection. The program captures rendered output into BMP files, which are useful for checking the final visual result.

### Typical build command
```bash
cd offline3/1905099
g++ 1905099_main.cpp -o show -lglut -lGLU -lGL
./show
```

## Prerequisites

- Linux environment
- `g++` compiler
- OpenGL and GLUT development libraries installed

Typical Linux setup:
```bash
sudo apt-get install build-essential freeglut3-dev libglu1-mesa-dev
```

## Notes

- The programs are academic implementations intended to demonstrate graphics concepts rather than production-ready applications.
- The outputs in `show` and BMP files are artifacts from the assignments and may be regenerated by compiling and running the corresponding source files.
- The repository is organized by assignment rather than by feature, so each `offlineX` folder can be treated as an independent lab project.

## Summary

This repository demonstrates a complete progression in computer graphics:

1. Basic rendering and object drawing with OpenGL
2. Transform pipelines and scene processing with matrix math
3. Ray tracing, lighting, and image generation with bitmap output

These offline projects together provide a solid foundation in 3D graphics, geometric modeling, viewing transforms, and shading.
